# Mahitala mineral illustrations

Original SVG artwork created for this website. These are conceptual illustrations,
not product photographs or crystallographic diagrams. Actual appearance varies by batch.

- `dolomite.svg`: faceted mineral cluster
- `phosphate.svg`: granular phosphate rock
- `palmash.svg`: palm frond and processed ash
- `clay.svg`: stratified clay layers

The supporting pictogram sprite is `../icons.svg`. It uses a 48 × 48 grid,
1.7-unit rounded strokes and `currentColor`, with a subtle secondary fill.
Keep illustrations decorative (`alt=""`) when the adjacent product title supplies
the accessible name. New pictograms should follow the same stroke/grid convention.
No third-party icon font, JavaScript dependency or image service is required.
